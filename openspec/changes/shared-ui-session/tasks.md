Milestone B evidence (no live acceptance claimed): on a 720-row fleet (the fixture repeated 120 times; `the_work_behind_one_keypress_stays_small_on_a_large_fleet`), a release build spends a median 0.32 ms (max 0.51 ms) on a navigation step and 0.06 ms (max 0.33 ms) on a filter keystroke, and 4.4 ms rebuilding the projection from an observation; a debug build takes about 5 ms, 1.5 ms and 19 ms. This measures the session's reducer, matching and projection only; input-to-render tails over the socket and under daemon load are not yet measured, and no input debounce or delta protocol was added.
